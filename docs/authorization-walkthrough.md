# OmniService 人工授权演示

[观看或下载 MP4](media/authorization-walkthrough.mp4)（2 分 06 秒，720p，中文旁白与字幕）

OmniService 管理台画面来自使用合成账号的本地流程。Telegram 和飞书的第三方授权界面为模拟示意，鼠标点击已高亮，二维码和凭据均为不可用的占位显示。

| 时间 | 操作 |
|---|---|
| 00:05 | 提供专用 Telegram Bot Token，按需隐藏输入模型 Key 或现有飞书 App Secret |
| 00:17 | 飞书扫码建应用，登记回调，配置长连接和可见范围，提交发布与审批 |
| 00:44 | 在安装流程中单独确认飞书管理者身份 |
| 00:52 | Telegram 原账号扫码配对，选择机器人、聊天范围和允许回复 |
| 01:09 | 打开团队管理网页，使用飞书登录并确认组织身份 |
| 01:20 | 生成员工邀请，员工使用同组织账号登录并接受 |
| 01:45 | 管理员核对并批准，确认员工加入 |
| 01:58 | 在飞书审批需要人工确认的对客回复 |

管理台录制对应本组织邀请流程。跨组织身份和外部群的接入仍待验证。
