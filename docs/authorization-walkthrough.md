## 客户端操作备选

已用命令行接入时以 [部署说明](personal-deployment.md#2-从命令行完成首次接入) 为准。没有兼容 TDLib 或需要在客户端核对时，沿用以下步骤。

1. **飞书创建和发布。** CLI 给出官方确认入口。核对应用所在组织、应用名称及预填的权限、群消息事件和卡片回调，再确认创建。管理员在应用的安全设置中登记完整回调地址，在事件与回调中确认长连接模式，核对应用可见范围并按组织规则发布及审批。
2. **飞书管理员身份。** 安装命令提示后，用预定管理员身份完成飞书授权，检查返回的身份与组织。
3. **Telegram 首次绑定。** 运行 `onboarding configure`，省去 TDLib 和 Telegram 登录参数。用预定的 Telegram 原账号打开终端给出的配对链接并点「开始」。在该账号个人资料的「设置 → 聊天自动化」选择专用机器人，核对要接管的聊天范围，勾选允许回复后保存。返回终端检查属于同一账号的 Bot API 回执。已有连接但回执过期时，可在客户端重新保存该机器人的授权。真实测试只用获准账号和群聊。

此节用于保留界面操作步骤。不得在录像、截图或共享日志中记录二维码、验证码、密钥和客户消息。
